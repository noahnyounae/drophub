# DropHub

<img src="public/static/logo.svg" alt="DropHub logo" width="96">

Two-way file exchange through single-use links, behind a Cloudflare tunnel.

- **Receive**: you generate an upload link; the sender drops **a single file** with it (the link is then closed).
- **Send**: you upload a file and get a **single-use** download link.
- Only the administrator (credentials in `.env`) can create links, list received files, verify, delete or revoke.

## Per-link options
Private label · expiry · max size (uploads) · password (scrypt) · sender name + message (uploads).

## Integrity (checksum)
The browser computes the file's **SHA-256** (piece by piece, without loading it into memory) before uploading.
The server checks **completeness** (size) and the **checksum** at the end. On failure the file is rejected and the upload link stays usable.
The sender gets the checksum as a transfer receipt; in the admin, the "Verify" button recomputes the checksum of the stored file.
For a send, the download page shows the SHA-256 (`sha256sum file`).

Files are transferred in 25 MB chunks (the Cloudflare free plan limits requests to 100 MB), with automatic resume after network hiccups.

## Getting started
```bash
cp .env.example .env     # then edit: ADMIN_PASSWORD, TUNNEL_TOKEN, PUBLIC_URL
docker compose up -d --build
```
Local admin: http://127.0.0.1:3000/admin

### Cloudflare tunnel
1. Cloudflare Zero Trust → Networks → Tunnels → *Create a tunnel* (Cloudflared); copy the **token** into `TUNNEL_TOKEN`.
2. Add a *Public hostname* (e.g. `drop.example.com`) pointing to the **HTTP** service `http://app:3000`.
3. Set `PUBLIC_URL=https://drop.example.com` in `.env`.

By default the admin interface is also reachable through the tunnel (`/admin`, protected by login + attempt rate limiting).
To restrict it to the local network: `ADMIN_VIA_TUNNEL=false`. You can also protect `/admin*` and `/api/admin*` with Cloudflare Access.

## Status and terms
`/status` shows a public health page (backed by `/api/status`) and `/terms` shows the terms of use, including the license and a link to the GitHub repository: https://github.com/noahnyounae/drophub. Both are linked in the footer of every page.

## Data
Everything lives in `./data` (SQLite database + files). Back this folder up.

## Development
The logo is generated by `python3 tools/make_logo.py` (standard library only) into `public/static/logo.svg`.
```bash
npm install
ADMIN_PASSWORD=password123 npm start   # Node >= 22.13
npm test
```

## Security at a glance
192-bit random tokens · links consumed only after a complete transfer (chat link previews don't burn them) ·
60-second download tickets · HttpOnly/SameSite=Strict cookies + anti-CSRF header · strict CSP · file names never used as disk paths.
